## 🎯 Specific Domain
Highly volatile physical replacement of bare RAM slots using `unsigned char` iteration. Represents the literal foundation wrapping OS `malloc` invocations universally.

---

## ⚙️ Core Mechanic & Algorithms
**Physical Byte-by-Byte Translation:**
Rather than manipulating typed data arrays (like `char **`), this domain explicitly converts inputs into hardware level `(unsigned char *)` trackers. 
`ft_memset` loops exactly `N` times, injecting specific data points directly across the allocated memory grid.
`ft_memmove` inherently protects against overlapping data corruption (an explicit failure state in basic `memcpy`) by tracing pointers natively from back-to-front when the destination address logically exceeds the source block footprint.

---

## 📜 POSIX & Shell Compliance
> [!IMPORTANT]
> **Calloc Initialization:** Uninitialized blocks of memory generated by OS `malloc()` requests possess ghost-data artifacts ("garbage bytes"). `ft_calloc` natively invokes `malloc()` and immediately chains a structural `ft_bzero` operation targeting every allocated grid slice to firmly inject absolute `\0` blanks. This creates flawlessly safe strings natively.

## 💾 Memory Contracts (Critical)
| Function | Allocates | Freeing Responsibility |
| :--- | :--- | :--- |
| `ft_calloc()` | `YES` | Wraps physical heap requests. The exact origin point for deep structural tracking. |
| `ft_memset()` | `NO` | Shifts bounds entirely in-place. |

## 🚨 Error & Signal Propagation
| Condition | Immediate Action | Upstream Impact |
| :--- | :--- | :--- |
| **Out Of Memory (OOM)** | `ft_calloc` triggers a hardware `NULL` response. | Aborts physical assignments. Protects caller natively. |
