
# 42cursus

Welcome to my 42 School curriculum repository! This repository contains my projects completed as part of the 42 programming curriculum.

## 📚 Project Structure

### Cercle 1
- **[libft](cercle-1/libft/)** - Custom C library implementation with standard functions
- **[libft_clean](cercle-1/libft_clean/)** - Organized version with categorized source files

### Cercle 2
- **[born2beroot](cercle-2/born2beroot/)** - System administration project
- **[ft_printf](cercle-2/ft_printf/)** - Recreation of the printf function
  - `srcs/printf/` - Core printf implementation
  - `srcs/printf/bonus/` - Bonus features (flags, width, precision)
  - `srcs/libft/` - Required libft functions
- **[get_next_line](cercle-2/get_next_line/)** - Function to read lines from file descriptors

### Cercle 3
- **[fdf](cercle-3/fdf/)** - 3D wireframe renderer
- **[pipex](cercle-3/pipex/)** - Recreation of shell pipe functionality
- **[push_swap](cercle-3/push_swap/)** - Sorting algorithm implementation

### Cercle 4
- **[minishell](cercle-4/minishell/)** - Custom shell implementation
- **[philosophers](cercle-4/philosophers/)** - Threading and synchronization project

## 🛠️ Technologies

- **Language:** C
- **Build System:** Make
- **Standards:** POSIX compliant, following 42 Norminette coding standards

## 📖 About 42

42 is a tuition-free, peer-to-peer learning programming school. The curriculum is structured in a circular progression system where each "cercle" (circle) contains progressively challenging projects.

## 📝 Notes

Each project directory contains:
- Source files (`.c`, `.h`)
- Makefile for compilation
- Subject PDF (in `subjects/` folder)

## 🚀 Usage

Navigate to each project directory and use `make` to compile:

```bash
cd cercle-1/libft
make
```
